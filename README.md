# Privacy Policy for Revival Mode
**Effective Date:** November 25, 2026

Revival Mode ("we", "our", or "the app") is designed to help users reduce mindless short-form video scrolling on Android devices while maintaining complete privacy.

## 1. Zero Data Collection & Offline Operation
Revival Mode operates 100% offline. The app does not request the `android.permission.INTERNET` permission and cannot transmit any data off your device. We do not collect, store, sell, or share any personal information, usage analytics, or device identifiers.

## 2. Use of Android AccessibilityService API
Revival Mode uses Android's `AccessibilityService` API solely on-device to detect when short-form video interfaces (YouTube Shorts and Instagram Reels) are active on your screen so it can trigger your focus redirection.
- **Strictly Scoped:** The service is restricted to monitoring `com.google.android.youtube` and `com.instagram.android` only.
- **No Screen Recording or Keylogging:** Screen content is never recorded, logged, saved, or transmitted anywhere.

## 3. Local Storage
Block counters and preference flags are stored strictly locally on your device using Android `SharedPreferences` and are deleted automatically if you uninstall the app.
